## Dev_Ex_Flow Project Specifications

🚀 **WebService** : This will implement endpoints Hello and GetDate.
🚀 **WebPortal**  : This will implement the portal that accesses the Hello and GetDate endpoints when a button is clicked.

---

## 📌 Problem (Core Idea)

Just an exmaple to see if AI generated code works and a usefull Webservice and WebPortal can be developed.
Also implement a SDLC flow to show the use of GenAI. In this case use Cline and Mistral-Code.
