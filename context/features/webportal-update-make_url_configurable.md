# Java + Spring Boot Setup

## Overview

Use the WepPortal project and make the now hardcoded url for the REST calls in Callcontrol.java.

## Requirements

- Use the WebPortal project see /WebPortal and use Project Reference as reference.
- In the REST requests to /Hello and /GetDate endpoints make the BASEURL configurable via an environment property style "BASEURL/<endpoint>" where endpoint is Hello or GetDate.
