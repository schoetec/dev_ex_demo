# Java + Spring Boot Setup

## Overview

Set up basic hello world type of example for Java and Spring Boot.

## Requirements

- Use Java 
- Use Spring Boot 
- Create simple web service that return `Hello World` html page when the /Hello endpoint is called
- Use HTTP for now
- Generate maven build file for maven version 3.9.14
- Generate windows powershell script to runf the webservice jar
- The web Service may run on port 8080
- Add the /Hello endpoint in class called EndpointController
- Add and extra default endpoint as landings page with a link to the /Hello endpoint.
- Ensure the app main is in the HelloWebService.java class. This object should contain all the startup initialization.
