# Java + Spring Boot Setup

## Overview

Use the WepPortal project and add an errormessage dialog if the clicked button action returns an error.

## Requirements

- Use the WebPortal project see /WebPortal and use as reference @constext/features/webportal-add-new-vaadin-portal.md
- In the mainview buttons are added, when clicked they will do a REST request to a WebService.
- If these REST request fails then show a nice error dialog with the assumed error.
- update the current existing buttons and REST requests as mentioned in CallController
